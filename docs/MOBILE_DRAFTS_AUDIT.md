# 手机开单、草稿恢复与审计

## 开单

销售、退货、调拨、采购共用商品搜索：输入名称、规格或 SKU，再点击明确的结果。键盘方向键可以选择，回车确认；多个相似结果不会直接选第一项。数量支持加减，按瓶或按箱分别填写，手机底部保留金额和提交按钮。

销售客户搜索修改文字后需要重新选择客户；退货重新查询原单后需要重新选择关联单，避免文字与实际编号不一致。采购校验失败时保留供应商、仓库、日期、商品各行和备注。

## 两种草稿

- **本机暂存**：填写时自动保存在当前浏览器，按租户和账号分开，保留 7 天。重新打开同类表单可查看、恢复或丢弃；恢复后先核对客户、仓库、箱规和金额。清除当前暂存不会清空表单，再次修改会重新暂存。
- **服务器草稿**：销售、退货和调拨点击“存草稿”或“保存修改”后保存到服务器，按账号权限可在其他设备继续编辑。销售列表新增“草稿箱”，手机列表可直接继续编辑。采购提交会立即入库，其自动暂存仅在本机。

本机暂存依赖浏览器存储；清除浏览器数据、超过保留期或存储不可用时不能保证恢复。共用设备用完后及时清除。暂存不保存密码、Cookie 或 CSRF 凭据。

恢复前会联网核对这次提交是否已成功，已成功的内容不再恢复提交。连接失败时保留内容供查看，联网后再恢复；成功提交确认后清除对应暂存。页面已打开时可继续填写，但本功能不提供离线打开页面或离线入账。

多窗口同时编辑同一服务器草稿时，后保存的旧版本会被拦截。旧暂存可以展开核对，再在新版本中重新填写需要保留的部分。商品不可选或箱规变化时也会拦截直接恢复，避免沿用过时的数量换算。

## 操作日志

日志仅供拥有“操作日志所有者”权限的管理员查看和导出。

新日志覆盖销售、退货、调拨和采购的创建、编辑及已有状态操作；收款、退款、采购删除、销售草稿删除和手动库存调整也留痕。记录业务字段前后内容、商品明细、库存差额、操作人和请求编号。页面展示实际变化，导出包含明细；不会记录整份请求正文或凭据。

可按北京时间日期、操作人、动作、对象和编号筛选，每页 50 条。导出沿用筛选条件，一次最多 10000 条，超限请缩小范围。历史日志保留原说明，不补造旧快照。

单据和库存操作的审计与业务写入使用同一事务，审计失败会一起回滚。审计表禁止普通 UPDATE、DELETE，只能追加；拥有数据库管理权限的人仍可能更改数据库结构，这不是密码学防篡改存证。

## 维护与验证

启动时迁移增加草稿版本及审计字段，不修改已有账务金额或历史日志。编辑请求需要页面生成的 `_request_key` 和 `draft_revision`；缺失版本返回 400，版本冲突返回 409。重试同一次成功提交返回原结果，不重复写入业务和审计。

`npm test` 包含草稿结果查询、账号与租户隔离、版本冲突、幂等重试、单据状态与库存差额、审计失败回滚、追加限制、日志权限、日期边界、分页及 CSV 安全检查。

交付前在隔离演示库的 Chrome 桌面 1440×900 和手机 390×844 视口实测四类单据、刷新恢复、报错保留、连续点击、旧窗口冲突、断网后重连、账号切换及审计详情。手机视口测试不等同于真机 Safari 或安卓系统键盘测试。
