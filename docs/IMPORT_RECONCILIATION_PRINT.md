# 导入、对账与打印

本阶段补齐基础资料导入、库存盘点、客户逐笔对账、供应商采购核对及单据打印。续费逻辑未改动。

## 数据导入

管理员从导航“导入”进入，下载对应 Excel 或 CSV 模板，填写后上传，逐行检查预览，再确认整批写入。业务员无导入权限。预览保存在当前租户库，并绑定上传账号；离开页面后可从“最近导入批次”继续核对。

| 类型 | 导入规则 |
| --- | --- |
| 商品 | SKU、名称、基本单位必填；已有 SKU 跳过，保留原价格、单位和箱规。新商品自动建立所有仓库的零库存记录。 |
| 客户 | 名称必填且不能含空白；已有同名客户跳过。归属账号填写有效账号的登录用户名，留空为未指定。 |
| 供应商 | 名称必填；已有同名供应商跳过，保留原联系方式。 |
| 库存盘点 | 按 SKU 和仓库名称定位；实盘数量填写**基本单位的库存总数**，调整原因必填。预览显示原库存、实盘及差额。 |

支持 `.xlsx` 和 UTF-8 / GB18030 CSV，每次最多 1 MB、1000 条数据、20 列。Excel 只允许一个工作表，不接受公式、日期类型、链接、宏或旧 `.xls`；ZIP 解压内容限制 8 MB，工作簿解析另有时间与内存限制。电话号码和 SKU 建议按文本填写，保留前导零。

表头须来自对应模板。错误行会阻止整批写入；确认时重新校验档案和库存，变化时先提示，再由用户“重新校验”并核对。预览有效期 24 小时。业务写入、库存差额、审计和批次完成状态在同一事务中提交，失败一起回滚。

同账号当天再次上传同内容会复用批次，重复确认不会执行第二次。已经完成的盘点若要再次计数，点击“用此文件重新发起盘点”，生成当前库存的新预览，再核对确认。基础资料导入仅新增，不覆盖旧资料；本阶段不迁移历史销售、采购或收退款。

## 对账

管理员在“对账”选择客户和日期区间，查看期初、本期销售、收款、退货、退款和期末净余额，可导出 CSV 或打印 A4。单次最多 10000 条流水，超出后缩小日期区间。

金额以整数分记录。已审核单据入账，草稿和待审核不入账；分次收款与退款各有流水，反审核生成反向冲销。流水与单据变动、幂等凭证、审计一起提交，并禁止更新或删除。

**入账日期是实际审核、收款或退款当天**，原单据日期另行展示。区间之前的流水形成期初余额；净余额 = 销售 − 收款 − 退货 + 退款。分单正余额合计为应收、分单负余额合计为待退，两者不会自动跨单抵销。

升级到数据库版本 12 时，已有已审核单据按现存销售、收款、退货、退款累计金额在升级当天一次性“升级结转”。系统不能还原旧版本未保存的分次收退款时间，因此逐笔对账只能选择升级日或之后；不把旧累计收款伪装成历史逐笔流水。原单据仍保留原业务日期。

供应商对账按采购日期列出采购单及合计，支持 CSV 和 A4。当前系统没有供应商逐笔付款台账，**采购合计不能当作未付账款**。

## 打印

销售、退货、采购、调拨详情均有“打印 / PDF”入口。独立打印页提供 A4，以及单据的 80mm 票据布局；客户和供应商对账提供 A4。核对后点击“打印 / 保存 PDF”，在浏览器打印窗口选择打印机或保存为 PDF。

所有打印建议关闭浏览器页眉页脚，避免额外输出网址和日期。80mm 票据默认纸张为 80 × 200mm，请在驱动或打印窗口匹配纸张；长单据可以分页并重复表头。纸张支持和边距受实际设备、驱动与手机浏览器影响，正式使用前应在目标打印机试打一张。

草稿、待审核和拒绝单显示预览标记，不作为已生效单据。箱/瓶、赠品及销售退货后的结算余额沿用单据口径。客户可见备注会打印，内部销售/退货/调拨备注和成本字段不会输出。采购备注属于采购单说明，会打印。

打印沿用详情权限：管理员可打印，业务员只能打印自己的销售、退货和符合仓库权限的调拨；采购与对账仅管理员。打印页不缓存敏感单据。

## 开发与维护

`npm test` 包含 `tests/import-reconciliation-print-test.js`，覆盖格式校验、整批回滚、重复确认、再次盘点、租户隔离、逐笔结算、旧库升级及打印权限。前端交付还需实际浏览器桌面、手机视口实测。

新依赖固定为 ExcelJS 4.4.0、Multer 2.4.0、yauzl 3.4.0。ExcelJS 使用的 UUID v4 通过兼容 CommonJS 的 uuid 11.1.1 覆盖；brace-expansion 2.x 覆盖到 2.1.7，用于消除依赖审计漏洞。导入文件在内存中校验，不写入业务文件目录。
